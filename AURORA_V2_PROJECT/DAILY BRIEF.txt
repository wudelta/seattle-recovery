i have a python/django project called aurora that is an AI assisted website builder. i use the groq free tier for my AI. the challenge for me is how to interact with the AI for maximum efficiency. i have discovered that AI is most effective when it is highly focused on a very specific task. if i try to feed it too much information about the project the token cost is high and it is counter productive. the AI eventually starts forgetting constraints from the start of the session, which can last up to eight hours, and begins to hallucinate. then i get stuck in coding loops where it tries A, A doesn't work so it tries B. when B doesn't work it goes back to A and i spend precious time copying and pasting code before i figure this out. 

my solution is to develop an army of minions that handle very specific tasks. each operates independently from the others so it only has the instructions it needs to carry out the task at hand. for example, UI functions are handled by three minions: i have a model in my database called minion_UI_layout, minion_UI_logic, and minion_UI_style which handle HTML, javascript, and CSS respectively. these minions are not physical files, but are stored in a postgres model called DeltaDirectives. each entry has a directive (or minion) name, an instruction field that contains markdown for the AI prompt, and a contraints field that is a JSON object for the rules, or the thou shalts, and thou shalt nots. i need to populate these fields so i can start using the minions instead of refeeding an AI all my specific rules for each little piece of the puzzle.
